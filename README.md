# 14-Day C Problem Solving Bootcamp

This repository contains my practice and assignment work from a 14-day C problem-solving bootcamp.  
It is organized by module, live class, and assignment so each topic and exercise can be reviewed easily.

## Project Goals

- Build strong C programming fundamentals
- Practice solving algorithmic and logical problems
- Improve coding speed and accuracy through daily exercises

## Repository Structure

- `Module - 01` to `Module - 10` — topic-based class and practice content
- `Live Class - 01` — materials from live sessions
- `Assignment - 02` and `Assignment &&  Module - 04 & 05` — assignment solutions

## How to Use This Repository

1. Start with the module folders in order.
2. Review class examples and solve the practice problems.
3. Compare your approach with assignment solutions after attempting problems yourself.

## Notes

- Folder names are kept as provided during the bootcamp.
- This repository is intended for learning and revision purposes.
